# 功能检查源码归档说明

本目录的 `protocol.json` 在运行前记录了三个直接使用脚本的 SHA-256。
功能检查运行时，`acceptance.py` 的供电/双时钟检查被提取为独立函数以便单元测试；
已启动的 Python 进程继续执行此前导入的实现。这不是正式性能实验。

运行后，按这一项可逆重构恢复此前源码，并逐文件严格匹配运行前已记录的 SHA-256。
`tooling-recovered-by-protocol-hash.tar.gz` 包含这三个精确匹配的文件。
它是**运行后恢复的归档**，不冒充运行前创建的归档。原结果和 protocol 未改写。

后续常规检查入口也会在运行前自动归档源码；正式性能入口从一开始已有此保护。
